# Grabble

A TBLive word-building game.

Players continuously drag moving letter tokens from a shared pool into the next slot on their own word line. This first pass includes `/play/[CODE]`, `/display/[CODE]`, `/tv/[CODE]`, `/host/[CODE]` and `/admin`, with transient Durable Object room state and no D1/R2 dependency.

The dictionary is intentionally a compact demo list for the viability build and should be replaced with a fuller approved word list before public play.
